# Chernoff Faces

<p align="center">
  <img src="assets/images/cf_logo.png" alt="Chernoff Faces logo" width="180" />

Static website for **Chernoff Faces**, a small film and art collective founded by Malte Hueckstaedt.

## Pages

- `index.html` - home, animated pointer and project navigation
- `mother.html` - project page for *Mother*
- `about.html` - accordion-style FAQ/about page
- `contact.html` - contact form
- `imprint.html` - legal imprint

## Structure

```text
.
├── assets/
│   ├── css/      # global and page-specific styles
│   ├── fonts/    # display fonts used by the animations/pages
│   ├── images/   # logos and project images
│   └── js/       # shared animation/explainer script
├── docs/
│   └── content/  # markdown source notes
├── index.html
├── sitemap.xml
└── robots.txt
```

## Local Preview

No build step is required. Open `index.html` directly in a browser, or serve the folder with any small static server.
